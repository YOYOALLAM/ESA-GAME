# Approved scope and implementation roadmap

**Scope approved; implementation is iterative.**

1. Foundation: password routing, bilingual UI, profiles, local save, basic playable prototype.
2. 3D match engine: real player locomotion, ball physics, 11v11 AI, passing, shooting, defending, goalkeeping, camera controls, skills and animation states.
3. Rules: offside, fouls, cards, set pieces, substitutions, stoppage time, extra time and penalties.
4. Career: create player, training, contracts, national-team selection, awards, retirement and transition to manager.
5. Manager: formations, scouting, academy, staff, medical, finances, transfers, board objectives, press, tactical simulation and independent saves.
6. Authentic football database: Egyptian Premier League, LaLiga, Premier League, national teams, historical squads, legends, verified roster versions and rights audit.
7. Live hub: authorized football data API, fixtures, scores, lineups, standings, player statistics, comparisons, heatmaps when available, historical reports, verified transfer updates and opt-in alerts.
8. Presentation: stadiums, crowds, weather, commentary, replays, ESA TV, newspapers, trophies, customizable stadiums and accessibility.
9. QA: mobile/desktop performance, save migration, data freshness, source attribution, licensing, offline behavior, keyboard/touch/gamepad testing.

**Important:** Third-party API access, scheduled updates and notification delivery cannot be provided by GitHub Pages alone. Do not represent mock data as real-time football data.
